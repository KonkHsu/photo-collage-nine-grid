# 构图参考的使用范围

用户在当前任务中提供并明确确认“这个程度合适”的正向样张，可作为构图参考。它用于校准线条与图案的显著程度、连续性和留白平衡：连接可以清楚、成组、带状、跨格，留白保留在它们之间，不应自动削减成几根极细短线。初次使用或判断分寸时查看；用户更新偏好后以最新要求为准。

该样张不是固定物象或布局模板，也无需每次作为生成附件；缺少图片时仍可按文字规则执行。

只观察作品区域。参考中的物象不能作为新作品素材，除非用户另行授权。不固定黑底、低饱和度、宗教题材或对象位置。

## 可借鉴的关系

- 不同格有不同的局部重点，视线经过承接、转折和停顿，形成连续阅读感。
- 从素材轮廓、结构或纹样提炼线条和图案，在留白中延伸、断续接力、转译为另一主体的形态；局部穿插按需要使用，不要求每格堆叠。
- 协调的色彩基调与少量重音连接场景，各照片仍保留材质和识别特征。
- 相邻格可共享一部分物象，其他边界可以切换镜头。脸部或文字跨线以辨识与阅读效果判断。

## 本次布局如何落地

一起安排各行的安静区域、全部计划主体与连接路径。留白要形成有面积的停顿，不仅是物象周围的窄缝；暗部密集纹理、雾气或大量环境片段不算有效留白。每格有真实来源内容即可，不需填满。

规划时写清“源自哪里 → 简化成什么 → 如何经过留白 → 在哪个主体落下”。例如衣褶曲线可简化并转译为水流方向，建筑边缘可接力到另一主体的斜线，纹样的弧形可在另一局部回应。这些只是方法，实际线条和图案必须来自本次素材，不固定屋檐、云纹或宗教元素。

主体之间可以有距离，但关系须在画面中可见。线条和图案以足够可见的强度承担引导，可以形成连续段、重复节奏和带状联系，周围仍有停顿；不必全部相接或每缝必连。判断依据是形态接力是否成立，而非线条越少越好。避免等距孤岛和缺少素材依据的机械串联。

缩略观看时同时辨认安静区域与组团间的接力。过满时减少占画面积和环境填充；孤立时调整关系和源自素材的抽象延伸。不能仅用“有留白”“色调统一”或“素材齐全”认定通过。连接强度参照认可样张；主体与环境的堆积、抽象线条的清楚连续是不同的密度问题，不能混为一谈。
