# 创作提示词

使用已经看完全部照片后建立的完整布局。密度、来源、参考图各自的作用写清楚，提示词保持一致；不叠加互相抵消的旧规则。可选关系参考的使用范围见 `composition-reference.md`。

## 主提示词模板

从实际附上的照片创作一张正方形摄影蒙太奇母图，具有九格连续阅读感。画面有清楚可感的留白、和谐色调和局部镜头变化；从素材主体的轮廓、结构和纹样中提炼线条与图案，在留白中延伸、转译到其他主体，使各局部连续可读，配合色彩、尺度和少量穿插。无网格、内嵌间隔、编号、水印或新增标题。

主题与风格：{主题、具体艺术手法}。
色彩：{共同基调、明暗与饱和度层级、少量重音}。
全部来源：{N、文件与附件映射、主体 ID 与识别特征、目标 M、未采用及原因}。
留白布局：{各行成片安静区域的位置、范围与形状，使用什么低细节背景；永久保留区域}。
九格布局：{01–09 的有效来源内容、主体或组团大小、局部重点、与相邻格的承接或转折、局部留白}。
视觉接力：{A 的来源形态 → 提炼的线条/图案 → 延伸路径及经过的留白或格界 → B 的呼应落点；连续、断续、重复或形态转译方式；参照认可样张的连接强度}。
跨线安排：{确有作用的局部连接；不需要则省略}。
保真与阅读：{必要识别特征、字形或阅读要求}。

按完整布局协调安静空间、主体与连接路径，附带环境只进入必要范围。根据素材保留大小差异和不对称组团；每格有内容，但不平均塞满或等距居中。主体之间有空间，也有可跟随的视觉接力；线条从具体形态中生长，经过简化再呼应另一处形态，不浮在空白里充当装饰。不必每个主体物理相连，但主要组团不能各自成为孤岛。各主体可辨且面积合规，仍需控制整体密度。

每个主体合计可见面积最多为母图 1/3；这是上限，不是目标尺寸。尽量覆盖输入照片，目标 M≥N，不复制、不拆分同物象凑数，不把环境纹理铺满以证明照片已使用。仅保留有作用的原图环境片段。主要物象须有实际图片来源；不虚构文字、建筑、人物或其他叙事物象。

安静空间使用纯色、柔和色面或足够低细节的来源环境，允许有明确起点和落点的线条、图案连续穿行，或形成有节奏的带状联系，线条之间与组团旁保留底色空间。以用户认可样张为强度参照，连接要清楚可见，不一律限制为少量极细短线。避免满铺环境纹理和缺少形态依据的机械连线；抽象元素不计作新增主体。

## 分批时附加的信息

当前附件对应：{当前主体 ID}。
后续素材预留：{未附主体的 ID、计划位置和大小}。
永久留白：{各批保留的安静空间，以及其中已规划、与认可强度一致的视觉接力}。

未附上的主体不生成，其预留位置暂时保持安静。后续只在预留位置放入实际来源主体，必要时替换、缩放或重排；不得靠扩大组团或不断叠加消耗永久留白。每轮以完整布局核对。

## 针对性修正

实际问题：{区域及可见问题}。
需要保留：{已经成立的来源、识别特征、色调和关系}。
具体调整：{按实际问题选择：减去环境、缩放或移动组团、恢复安静区域；或从哪些素材形态提炼线条/图案，沿什么路径呼应哪个主体}。

判断过满先对照用户认可样张；明显、连续或带状的连接不自动等于过满。确实缺少停顿时减少实际占用，不以变暗、模糊或调色充当留白。关系不足时调整位置、朝向和尺度，提炼源自素材的线条或图案，补全具体形态之间的接力；不以新物象或环境填缝。一次减密修正仍失败时，回到原始素材按新空间布局重构，不继续沿用满铺底稿。

验收同时检查安静空间与视觉接力，再核对色调、来源、单体面积和九格非空。留白充足但主体成为孤岛，同样不通过。用户仅需母图时不切片。
